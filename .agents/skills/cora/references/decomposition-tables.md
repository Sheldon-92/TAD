# Decomposition tables

Packs below are pointers under the AGENTS.md "Capability Packs" rule (announce at most two; frozen packs are not auto-matched; naming a pack here loads nothing, Keyword match alone never loads a SKILL.md). Cora names at most two of a table's pointers. Every table ends with the two always-present rows, "Not wanted" and "Done check".

## App
| Block | What it settles |
|---|---|
| Who and where | who uses it and where |
| Core flows | what they do with it |
| Data and accounts | what is stored, who signs in |
| Platform and look | where it runs, how it should feel |
| Not wanted | what it must not do |
| Done check | how the result is judged |
Packs: `pack:web-frontend`, `pack:web-backend`, `pack:web-ui-design`, `pack:web-testing`, `pack:product-thinking` (frozen)

## Research
| Block | What it settles |
|---|---|
| Question and why | the question asked and why now |
| Decision fed | the decision the answer feeds |
| Scope | sources, period, depth |
| Output form | report, table, recommendation |
| Not wanted | what to leave out |
| Done check | how the result is judged |
Packs: `pack:research-methodology` (frozen), `pack:academic-research` (frozen)

## Science
| Block | What it settles |
|---|---|
| Question or hypothesis | what is tested |
| Method and measurement | how it is measured |
| Data and materials | what is available |
| Controls and validity | what could invalidate the result |
| Not wanted | claims or methods to avoid |
| Done check | how the result is judged |
Packs: `pack:academic-research` (frozen), `pack:ai-evaluation`

## Learning
| Block | What it settles |
|---|---|
| Goal | what he wants to be able to do |
| Starting point | what he already knows |
| Depth and time | how far, how long |
| Form | explanation, exercises, examples |
| Not wanted | what to skip |
| Done check | how he will know he learned it |
Packs: none

## Process / method
| Block | What it settles |
|---|---|
| Flow changed | which flow changes |
| Who uses it | who follows it |
| Replaces | what it replaces (not alongside) |
| Rules touched | which existing rules it meets |
| Not wanted | what must not change |
| Done check | how the result is judged (scenario walks) |
Packs: `pack:agent-orchestration`, `pack:ai-agent-architecture`

## Bug
| Block | What it settles |
|---|---|
| Seen | what he saw and where |
| Expected | what he expected |
| Steps and frequency | how to reproduce, how often |
| Since when | what changed |
| Not wanted | side effects to avoid |
| Done check | reproduce first, then it passes |
Packs: `pack:web-testing`

A type not listed is decomposed on the spot; a table is added when a new type is met.

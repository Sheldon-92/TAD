## 五列定义与取值

追加五列：严重度 / 判据 / 证伪条件 / 成本量级 / 防线关系。前两列为投影，成本量级与防线关系为新判断。

**严重度（投影自形态 B）**

- 取值域：高 / 中 / 低 / 未知（恰好一个）。
- 规则：取形态 B 该 `## Dxx` 段内所有 `严重度=X` 的 max（高 > 中 > 低）；该段零实例时填 未知。
- 不许推断：无实例只能是 未知，不得因"看起来重要"填 高。
- 严重度与「地板·可缩放」是两个独立维度，不得互相推导；严重度不驱动地板/旋钮判定。

**判据（投影自「三类判定」列）**

- 取值域：C1 / C2 / C3 / C4（恰好一个）。
- 映射：C1 = 1-留（有实例）；C2 = 2-退场（无实例但触发条件出现过）；C3 = 3-挂起（无实例且触发条件从未出现）；C4 = 4-威慑免死（无实例且失效场景理论上不可逆/高严重度）。
- 本列是**过滤器**，**不是排序器**：它把少数例外行从主群筛出，对主群内部不提供切分信息；不得暗示本列参与"谁进地板/谁进旋钮"的排序。

**证伪条件（投影自形态 B「地板·可缩放」）**

- 有证伪句的行：逐字照抄形态 B「地板·可缩放：」括号内末个「；」之后那句。
- 待判行：填 `N/A（待判·本行在 Phase 5 前不得拍板）｜前置：<源句>`。
- 待判 5 行清单：D07 知识评估、D08 跨模型审查、D09 配对测试、D11 Execution Mandate、D12 约束准入。

**成本量级（新判断）**

- 取值域（有序，低→高）：零 < 机械近零 < 机械一次 < agent一次 < 人一次 < 人多轮（恰好一个）。
- 零：无任何运行时动作（纯禁令/内置约束）。
- 机械近零：确定性程序，单次 <10 秒，无 LLM 调用。
- 机械一次：确定性程序，单次 ≥10 秒或需读写产物，无 LLM 调用。
- agent一次：1–2 次 LLM/subagent 调用，无人参与。
- 人一次：需人 1 次输入或裁定。
- 人多轮：需人 ≥2 轮往返。

**防线关系（新判断）**

- 取值域：独立，或 `同根→D<nn>` / `互补→D<nn>` / `冗余→D<nn>`（可多条，`；` 分隔）。
- 同根：两行防同一个失败的两个环节（删任一条另一条仍在但覆盖不全）。
- 互补：两行各挡不同失败类（删任一条另一条完全挡不住）。
- 冗余：两行挡相同失败类且覆盖相当（删任一条另一条基本挡得住）。
- 独立：无其他行与之有上述任一关系，须在防线关系列内举证（`独立｜理由：…「<失败类>」`）。

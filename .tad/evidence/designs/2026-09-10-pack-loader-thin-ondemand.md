## Architecture

```
user task
  → match keywords/descriptions against pack-registry.yaml
  → DROP if status == frozen (missing status == active)
  → cap 2 POINTER announcements (name + one-line when + SKILL path)
  → do NOT Read SKILL.md
  → escalate to Read SKILL.md IFF:
       (i) human names the pack / "load pack" / confirms step1_5b, OR
       (ii) recorded failure-retry (Layer 1 retry / Gate FAIL / human: generalist wrong)
  → references/*.md only via that pack's own Step 0/1 after SKILL is in context
  → collision advisory only among already-escalated packs
```

**Derived registry vs durable freeze:** `pack-registry.yaml` is generated by `.tad/scripts/scan-packs.sh` (not a hook). Durable `status` lives on `CAPABILITY.md` frontmatter (`status: active|frozen`, default active if omitted). Scanner emits `status:` on each pack row. Loaders read the **registry** field; they must not invent a second SSOT (`deprecation.yaml` is out).

**This ticket does not set any live pack to frozen** (inventory is Pass 2). Scanner + loaders must still honor `frozen` when present (fixture `--packs-dir`).

## Escalate record (failure-retry)

A **recorded** failure-retry is one of: a Layer 1 retry note naming the pack; a Gate FAIL / honest_partial citing missing pack judgment; or a human sentence that the generalist output was wrong **and** naming/implying the pack. Keyword overlap alone is **not** a record.

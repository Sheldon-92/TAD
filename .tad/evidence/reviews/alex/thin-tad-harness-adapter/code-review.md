## Security verdict

- **Injection — FAIL (blocking, F02):** missing `--` separator exposes CLI flag injection from prompt content. Fix is one token (`--`) plus `-f` preference. No shell injection elsewhere (runner uses argv arrays, no shell — runner.mjs lines 262–275 — and adapter quotes correctly), but the prompt-content leg re-opens injection at the CLI-parser layer. Must fix pre-Gate-2-PASS.
- **Env hygiene — FAIL (blocking, F04 + P2 F12):** the allowlist strips the handoff's own control variable, so the documented override cannot work through the runner; direct invocation inherits the full env with a misleading "净化" comment. Fix allowlist + boundary doc pre-Gate-2-PASS (F04); F12 doc fix at implementation.
- **Traversal / symlink / containment — FAIL (requires fix at implementation, F06 + F07):** no canonicalization, no workdir containment, `cat` of arbitrary prompt paths, TOCTOU acknowledged-but-unaddressed. Combined with forced `--auto`, this is the highest-blast-radius finding. The handoff must add the realpath/prefix rule before PASS counts as meaningful; tests proving containment land at Gate 3.
- **Exit-code integrity — WEAK (F08):** codes themselves are chosen well (127/2/passthrough), but the composition into `SPAWN_FAILED/ETIMEDOUT/FAILED_INFRA/FAILED_MODEL` is unspecified and mis-retries deterministic usage errors. Not an injection, but it can burn paid invocations on never-succeed retries. Fix the mapping table pre-PASS (text-only), prove it with unit tests at Gate 3.
- **Timeout / DoS — ACCEPTABLE with doc fix (F13):** runner group-kill design is sound and `exec`-compatible; no in-adapter timeout needed on the runner path. Direct-invocation `timeout` wrapper must be documented. Prompt-file size cap (F03) doubles as a memory-exhaustion guard.
- **Overall:** no shell-injection via `eval`/`system`/unquoted expansion found; no secret handling introduced; telemetry path correctly avoids currency. The design is containable — all security findings are fixable without architectural change, which is why the verdict is CONDITIONAL PASS rather than FAIL.

## Knowledge Assessment

**New discovery (project-knowledge candidate):** three adapter-contract traps worth one pattern note — (1) `sanitizeEnv`-style allowlists silently strip the adapter's own `*_RAW_BIN`-tier variable unless both tiers are allowlisted together; (2) PREREQ self-checks using `<(…)` process substitution always fail `[ -f ]` gates — use `mktemp` files; (3) prompt-as-positional without `--` re-opens flag injection even when the spawn path is shell-free (argv-array safety ≠ option-parser safety).

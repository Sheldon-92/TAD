## Item 1 — Static imports / subprocess primitive (PASS, 1 P2 note)

- `pilot.mjs:29-33`: only `node:fs`, `node:path`, `node:url`, `node:crypto`, `node:child_process`. No `fetch`, no `http/net/dns`, no `eval(`/`new Function(`/`vm`, no `import(`/dynamic import, no `require(`. Grep over the file confirms zero `spawn(`/`spawnSync`/`exec(`/`shell:true` (the 4× `shell` hits are comment/policy strings at `pilot.mjs:9,88,94`, and `pilot.mjs:748` is a disclaimer string).
- Sole subprocess primitive is `execFileSync`, called at exactly two sites (`pilot.mjs:183` in `gitOut`, `pilot.mjs:192` in `gitBlobBytes`), both `execFileSync('git', argv-array, { cwd: REPO_ROOT, ... })` with no `shell` option (default `shell:false`). No `-c`, no string command, no model CLI.
- [P2] Test weakness (not a pilot hole): `pilot.test.mjs:50` — `assert.ok(!src.includes('execSync') || src.includes('execFileSync'))` is vacuous (second disjunct is always true while `execFileSync` exists). If someone later adds a bare `execSync`, this assertion still passes. Required fix: assert `!src.includes('execSync') || every occurrence is part of 'execFileSync'` via regex, plus explicit `!includes('spawnSync')`, `!includes('execFile(')` already covered at `pilot.test.mjs:51`, `!includes('shell:')`.

- [P2] Prefix-boundary imprecision: `pilot.mjs:173` uses `norm.startsWith(pre)` with directory prefixes lacking a trailing separator — `.tad/config` (`pilot.mjs:80`) also matches `.tad/config-evil`, and `.codex/hooks.json` (`pilot.mjs:84`) matches `.codex/hooks.json.evil`. ## Item 7 — Test-env overrides PILOT_PRIVATE_ROOT / PILOT_SOURCE_ROOT (PASS with residual risk, P2)

Residual risk transfers fully to P2: the harness must scrub `PILOT_*` from any model-visible environment, run verification in a separate clean env with the bundle path pinned, and treat verifier output as valid only from that env.
- Adequacy of the note: adequate for P1 scope (README + code header + `readiness.md` boundary per handoff §4.3/§6.2). Required P2 action (not a P1 fix): restate as a MUST in P2 harness spec — env scrub list including `PILOT_PRIVATE_ROOT`/`PILOT_SOURCE_ROOT`, plus a pre-run assertion that `privateRoot()` equals the pinned path.

## 1. 什么时候开，什么时候关

**关（默认）。** 改文案、改流程、改代码、普通润色，都当这页不存在。人没点名，PM 不得自己打开。

**开，只有一种情况：** 人用嘴点名「这刀是在调 agent，或在设计 agent」，并且点到具体对象（哪一份 prompt、skill、工具说明，或哪一段 agent 行为）。猜出来的不算点名。

开了只多下面这几条纪律。验收仍走现有门 3、门 4；知识勾选（KA）和盘⇄私有脑双写照旧。不新开验收 Agent，不新编 Gate 编号。

出现任一条就关掉，已开的爬坡停在当前轮，不自动续：

- 人说停，或改口说这不是调/设计 agent
- 没有人签过的题（输入）和判分尺（grader）
- 开跑卡上没有预算和停止条件
- 花费要越过常规：按 L3 先问人；人没批就停

讨论记录和本草稿都不等于点名，也不授权开跑。

## 2. 开跑卡（点名之后、第一轮之前）

PM 把卡摊给人看。缺一项就不开跑。agent 不得自己把题和尺子定死。

1. **对象。** 这刀改哪一份说明，写路径。一次只挂一个对象。
2. **人签收的输入。** 题从哪来：生产样例，或人手写。人可以拒签；拒了就停，不许默认 yes。
3. **人签收的 grader。** 怎样算对、怎样算错，人签在卡上。
4. **两面分开。** 训练面：改的时候可以看的题。对照面（held-out）：本轮不许看、收口只报它们。题号或路径写明，不要混。
5. **五行 audit，先答再改。** 缺一行 = 没有开跑卡。
   - task：这轮要检出的行为是什么
   - harness：怎么跑、环境是什么
   - metrics：看哪个数
   - grader：谁判、判据是什么
   - 能否检出变化：行为没变时这套题会不会 FAIL；变了，分数会不会动
6. **噪声地板。** 什么都不改，同一套对照题重跑，抖动有多大。地板大于或等于你愿意叫做「改进」的最小涨幅，后面的分数差就不算改进。
7. **一轮只改一处。** 本轮只动 prompt，或只动工具说明，或只动另一处。不捆绑。
8. **预算和停止。** 最多几轮、花到哪停。停滞了先停下来分分类，再决定烧不烧下一轮。加预算 = L3，先问人。
9. **失败放哪。** 失败样例只留证据路径。不许贴进正在被优化、而且会进模型上下文的那份说明。

## 3. 门 2：PM 查盘，不代跑

过程门 2 还是原来的：至少两名独立审、证据落盘、P0 清零。PM 只查盘，不另开一场代跑。

这刀额外核对开跑卡是否落在证据里：

- 五行（task / harness / metrics / grader / 能否检出本轮要的变化）缺一行 → 不放行实现。
- harness 或 grader 相对开跑卡有改动，但没有人另行批准 → 不放行。
- 本轮 diff 同时动了两处以上（例如 prompt 和 grader 一起改）→ 打回，拆成一轮一改。

门 2 过了只说明可以开始改。文件在、审过了，不等于行为变好，更不等于可以报改进。

---

## 4. 门 4：标题只看没收进本轮修改的对照面

收口仍走现有门 3（没证据不报 PASS、不送门 4）和门 4（对照人已批的结果合同，写是/否加一句）。KA、双写、该走的 human-look 照旧走。

这刀的门 4，标题数字**只来自 held-out（对照面）**。PM 核对：

- 标题用了训练面分数，或用了本轮改说明时见过的失败题 → 不得报 PASS。训练面涨、对照面不动 = 过拟合，回滚该轮，不报改进。
- 涨分落在噪声地板里面，或没有先量过地板 → 不得说「改进成立」。
- 标题数字从原始记录重算，不信摘要标题。不把厂家博客数字写成我们的门槛。
- 失败案例已经写进被优化的那份说明 → 本轮作废，不送门 4。
- 爬的过程中改过 harness 或 grader，没有人批 → 门 4 不收。

对不上就 FAIL、PARTIAL 或诚实 BLOCKED。禁止缩小范围换绿票。禁止用「文件在、闸勾了、独立审也 PASS」冒充效果变好。

## 5. 不要做

- 不要默认打开。人没点名「调 agent / 设计 agent」，就当这页不存在。
- 不要改 TAD SKILL、模板、Gate 清单，不要把这页升成原则层。
- 不要装 Claude Code，不要跑别人的 build-eval / hillclimb 命令，不要把爬坡叫成现有档位的别名。
- 不要把失败样例贴进被优化的 prompt 或 skill。
- 不要一轮改多处；不要为了过线悄悄改 harness 或 grader。
- 不要用人没签的题和尺子，不要替人点 yes。
- 不要把训练分、见过的题、或小于噪声的涨分写成门 4 标题。
- 不要用别人自报的涨分或省钱比例当验收线。
- 不要新编 Gate 编号，不要让 PM 代跑门 2。
- 花钱越过常规仍是 L3。本草稿不授权开跑。

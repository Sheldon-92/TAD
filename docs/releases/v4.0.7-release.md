# TAD v4.0.7

Minor-feature patch. Two Epics: updating TAD in one sentence, and Cora deciding route and spend herself.

## What changed

- One-sentence update: "升级 TAD" (or `/tad-update`) runs a check, then one confirmed run updates every platform in the list. The installer pins `/bin/bash`.
- Changed-only backup, an update report saying which files changed (and that project files are unchanged), an "After this update" block, a once-a-day reminder when a newer TAD exists.
- Backup lifecycle: old backups move to a holding area, are cleared only on a listed yes; "看备份" shows the TAD files your project edited and absorbs one into `.tad/project-knowledge/salvage/` on a yes.
- Cora owns route and spend: result first, a fixed floor, a twice-the-estimate checkpoint and a three-times stop, one end line per matter (`Route | Spend | Why`).
- Paid run means billed separately in real money; sessions under your subscription plans are ordinary work, named in the plan and the end line.
- Down 1 trigger no longer contradicts its own lead-in ("no Down 2 on a no-patch trigger").

Sources: `.tad/archive/epics/EPIC-20261022-tad-update-flow.md`, `.tad/archive/epics/EPIC-20261023-cora-route-judgement.md`; completion `.tad/evidence/yolo/tad-update-flow/EPIC-COMPLETION.md` and `.tad/evidence/yolo/cora-route-judgement/phase1-gate-report.md`.

## Upgrading

The first update into 4.0.7 runs through each project's old `/tad-update` (the old helper, one confirmed run). The full flow starts from the next update after that. `4.0.6-to-4.0.7.yaml` removes and renames nothing. Command: `bash tad.sh --platform claude-code` (or `codex|opencode|cursor`, or a comma list), or `--source`. On macOS with Homebrew bash 5.3.x first on PATH the old installer can exit 139; run again or use `/bin/bash tad.sh`.

## Known gaps

Update flow: absorbing an edited TAD file copies any secret it holds into `salvage/` (per-item yes, diff seen locally first); a held item's `released` rows rest on the stored digest; `classify` echoes path arguments raw (not on a relayed flow); the `brain-index.md` minute stamp shows as changed on every update; the first check screen does not count the backup files it will move; "看备份" misses an edit in an older in-project backup; the same-yes clear ran only in fixtures; node 24.7.0 segfaults intermittently in `tad-install-fixture`; Codex not measured, Cursor and OpenCode live behaviour measured once each.

Cora route judgement: Up 7 (hardening rework for a carried P1 on a deletion, security or data path) has no scope; the acceptance message lists every `decided:` line unordered; a decided narrowing may touch the Requirement text; stop reason 2 does not name a missing reviewer; the dispatch count undercounts retries. No live Cora matter has run the new rules yet.

Release rule: the `git archive` shape of the release commit is installed into one throwaway project before the tag (record: `.tad/evidence/simple/2026-10-24-release-407-completion.md`, local).

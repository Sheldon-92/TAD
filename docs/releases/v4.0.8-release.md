# TAD v4.0.8

Measurement-and-reliability patch. The R4 batch (measurement layer, code-metrics accounting, adopted review items) and the three fixes its distillation filed.

## What changed

- A judge-case set (`.tad/eval/judge-cases/`, v1 provisional: 2 failure cases, 2 controls) for replaying judge changes against recorded outcomes, with a standing qualification on what a replay that size can claim; incident records gain a should-have-blocked layer field.
- Replay and evaluation work pre-declares criteria and assertion layers; evidence claims carry a strength label; state surfaces mark disk-verified statements; an AC dry-run is a standing authoring step.
- Code metrics (crapper, mutator; both 0BSD, six languages) record on the Gate 3 evidence surface only — no thresholds, not a criterion, no pilot site chosen yet.
- Brain-index routing has a standing verification (first round: Recall@3 8/8, false alarms 0/5); two checker hard forms now fail closed on a malformed date cell or broken anchor.
- The tiering rule's executable text moved into the handoff-creation protocol, with a standing self-check that names a chain's replay step up front when its write set hits the replay-trigger class.
- gate3-check.sh no longer reports missing evidence on complete review files (six location/normalisation fixes; classification semantics unchanged; deliberate deletions still fail loudly). One explained residual line remains — see Known gaps.

Sources: `.tad/archive/epics/EPIC-20261027-r4-batch.md`; completion `.tad/evidence/yolo/r4-batch/EPIC-COMPLETION.md`; the three tickets `.tad/active/TICKET-20261028-checker-false-negative.md`, `TICKET-20261028-handoff-creation-loadpoints.md`, `TICKET-20261028-r4-distill-text-pack.md` (closing section at the end of each).

# TAD v4.0.12

Patch release. It ships the framework changes made since the previous release on two machines (the Mac and a second machine): the pack-meta read guards in the installer, the report upgrades (README, pack counts, no-git test runs, failure-path checks, temporary copies), the `design-foundation` pack, and a set of smaller tickets. The release tree is the public base plus an allow-list of framework files; working notes and process records keep their public copies.

## What changed

- **Pack-meta reads no longer abort the installer** (Mac). A 0-byte `.tad-pack-meta.yaml`, or one without `sync_policy` or `baseline_source`, no longer stops an install or an upgrade. `PACK-META-EMPTY` names 0-byte metas before the backup; `--fork-pack` refuses a meta without `sync_policy` and changes nothing; `--list-packs` and `--unfork-pack` no longer abort. Cases `pm.empty`, `pm.nopolicy`, `pm.nobaseline`, `pm.maint`.
- **Report upgrades** (Mac). README install line without `--platform` and a "First thing: a real run" section; pack counts from the registry (`pack-counts.sh`); `run-all.sh --no-git`; `check-path-refs.mjs` without git; handoff §8.7 failure paths and `failure-path-fixture.sh`; §8.8 research truth check; `cora-check.sh judge-first` and `rounds`; `harness-precheck.sh` and `tad-tmp.sh`; installer snapshot keep rule; Cora, Blake and gate text.
- **`design-foundation` pack** (second machine), with tokens and a token parity check; web UI design template and brand-token changes; a design-tokens template.
- **Tickets** (second machine): component health check (the project-owned baseline is not shipped), intent-route test wired into `run-all.sh`, hook-timeout consistency for Codex and Cursor hooks, version-sweep gaps in `release-verify.sh`, `startup-health.sh`, step-gate checker lens naming, sign-off layer text.

## What this release holds back

- Working notes and process records under `docs/pm/`, `.tad/active/` and the other project-owned directories keep the copies the public repo already has. The thirteen moves of working notes into the archive are not shipped as deletions. Project-knowledge pattern updates stay out. The downstream version ledger (`.tad/evidence/pm/downstream-versions.md`) stays at its previous-release copy; it was not rescanned.
- Two files that belong to neither the framework nor its documents are held: the CI workflow file and a review benchmark record. The maintainer was asked whether to publish them.

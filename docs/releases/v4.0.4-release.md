# TAD v4.0.4

Patch. Cora clarifies a request by decomposing it into blocks, every review path uses at least two reviewers with different lenses, the gates have written conditions, the builder never signs Gate 3, and Gate 4 is an AI real run. The Full Layer 2 review brakes (accepted 2026-10-18) are merged in as limits.

## What changed

- Cora clarification: she splits the request into blocks and asks only the unclear ones, one block at a time, at most 4 questions each, with options, a marked recommendation and "other", after giving her own professional view. On "just do it" she plays the requirement back one line per block and you confirm first. Direct `/alex` uses the same method. `tad-elicit` and the old Socratic inquiry protocol are removed.
- Reviews: one reviewer contract (`.tad/templates/review-contract.md`) is loaded by every review, and every path has at least two reviewers with different lenses (no task_type tiers, no express exception). Only P0/FAIL/PARTIAL block; P1 is carried to the human. Rounds converge; round 3 with an open P0 looks upstream.
- Gate 1 has conditions and a format check that rejects placeholders. Gate 3: the run reviewer re-runs every acceptance command and real path by hand in one throwaway project copy; `gate3-check.sh` executes nothing and only checks that the evidence is complete (scripted execution was dropped after three review rounds found escapes). Gate 4 is an AI real run or browser run against the requirement; no human is added. An escape log records which gate should have caught each late defect.
- Layer 2 review brakes merged: the round count includes R1 and is never reset by recovery (only a re-plan restarts it), no round 4 without a re-plan, a standing BLOCKED_RISK veto, escalated/blocked/aborted/not-run states are never clean completion, and findings keep their original severity until a reviewer of that lens closes them.

## Upgrading

Update with `bash tad.sh --platform claude-code` (or `codex|opencode|cursor`) or use `--source`. `4.0.3-to-4.0.4.yaml` deletes the four retired files when unmodified (`tad-elicit/SKILL.md`, the Socratic protocol, `requirement-elicitation.md`, `elicitation-methods.md`).

## Known limits

- Not used in a real session yet; browser-driven Gate 4 and Linux not exercised. The merged brakes have not run in a Layer 2 loop; `loop-config.yaml` still has the older `priority_groups` block.
- An update from 4.0.3 may leave an empty `tad-elicit` directory (and on Claude Code a link to it); not checked on a real update.
- Release rule: the `git archive` shape of the release commit was installed end to end into one throwaway project before the tag (record: `.tad/evidence/simple/2026-10-19-release-404-completion.md`, local). One real download install from GitHub right after the tag is still open at release time.

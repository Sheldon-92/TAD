# TAD v4.0.3

Patch. v4.0.2's download install and update refused the archive; this release fixes it and carries a lighter Cora flow.

## What changed

- Download install/update fixed: the release archive no longer contains the source repo's `.claude/skills` links (`../` targets, rejected by the tar-slip guard). They are kept out by `export-ignore` in `.gitattributes`; the guard itself is unchanged. `release-verify.sh archive-links` now blocks any release archive that carries an escaping link.
- Cora lighter flow (protocol changes, not measured): simple and reversible-handoff work starts in the same turn as the stated plan and the human's "wait" or "no" stops it; an Epic's "continue", one-way handoffs and push, tag, publish, delete, credentials and spending still wait for him. Empirical P0s are settled by a spike before a design fix, a P0 must state a failure scenario, and the Budget is an estimate that stops only at twice the estimate or for money.

## Upgrading

Do not fetch 4.0.2 by download: its archive is refused. Update straight to 4.0.3 (`--platform claude-code|codex|opencode|cursor`) or use `--source`. No file deletes or renames; `4.0.2-to-4.0.3.yaml` is an empty hop.

## Known limits

- The lighter Cora flow was reviewed and gated but not measured on a fresh session.
- The fix was proved on a `git archive` build; a real download install from GitHub after the tag is still open at release time.
- GNU `cp` behaviour (from 4.0.2) was tested through a PATH shim, not on a real GNU host.
